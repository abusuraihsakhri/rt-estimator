Rt Estimator

Estimate the time-varying effective reproduction number from daily case incidence using the Cori et al. (2013) renewal equation and Gamma posterior.

Local browser processing

1. Incidence and assumptions

Requires a cases, incidence or count column, optionally date. One row per consecutive day, including zero-case days.

Synthetic example available below. Maximum 5,000 observations.

A Gamma-distributed non-negative serial interval is discretized with w(0) = 0. Smoothing creates fractional incidence; posterior intervals then reflect the stated model approximation.

2. Rt estimates

Load an example or enter incidence data, then select Calculate Rt.

Methodological limitations. Rt estimates depend on the supplied incidence, serial interval, prior and smoothing choices. Reporting delays, missing dates, changes in testing, imported cases and near-zero infectiousness may bias interpretation. Results are for research and educational use, not individual clinical decisions.

All case data and computations remain in this browser. No uploads, cookies, analytics or external APIs are used. See the source repository for the Python CLI and API.
